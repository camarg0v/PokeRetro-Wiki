Sobre o Projeto

O PokeRetro Wiki é um projeto acadêmico desenvolvido para a disciplina de Web Design. O principal objetivo foi aplicar os conhecimentos de HTML5 semântico e CSS3 para construir um website funcional e estilizado.

A escolha do tema "Pokémon Retro" busca homenagear a estética 8-bit dos jogos clássicos da franquia (como Pokémon Red/Blue/Yellow), utilizando paletas de cores limitadas, fontes pixeladas e um layout que remete aos primórdios da web.
