Sobre o Projeto

O Pokemon World é um projeto acadêmico desenvolvido para a disciplina de Web Design. O principal objetivo foi aplicar os conhecimentos de HTML5 semântico, CSS3 e JavaScript construir um website funcional e estilizado.

A escolha do tema "Pokémon World" busca criar um site temático para fãs de Pokémon, com páginas interligadas, mídias, curiosidades e um design responsivo.

Tecnologias Utilizadas

  • HTML5
  • CSS3 (Flexbox/Grid para layout)
  • JavaScript (funcionalidades)
