Sobre o Projeto

O PokeRetro Wiki é um projeto acadêmico desenvolvido para a disciplina de Web Design. O principal objetivo foi aplicar os conhecimentos de HTML5 semântico e CSS3 para construir um website funcional e estilizado.

A escolha do tema "Pokémon Retro" busca Criar um site temático para fãs de Pokémon, com páginas interligadas, mídias, curiosidades e um design responsivo.

Tecnologias Utilizadas

  • HTML5
  • CSS3 (Flexbox/Grid para layout)
  • JavaScript (funcionalidades)
