# 🌟 PokéRetro-Wiki

Projeto desenvolvido para a disciplina de *Web Design* utilizando *HTML e CSS*.

## 🎯 Objetivo
Criar um site temático para fãs de Pokémon, com páginas interligadas, mídias, curiosidades e um design responsivo.

## 📄 Páginas
- index.html: Página inicial
- pokedex.html: listagem de pokemons
- treinadores.html: lista de treinadores da região de kanto
- regiões.html: informações como fauna e flora, de cada região
- sobre.html: Formulário de contato, informações sobre o projeto e motivações

## ⚙ Tecnologias
- HTML5  
- CSS3  
- JavaScript  

## 🚀 Deploy
O site está hospedado no GitHub Pages.
