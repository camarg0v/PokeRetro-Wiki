# 🌟 PokéRetro-Wiki

Projeto desenvolvido para a disciplina de *Web Design* utilizando *HTML e CSS*.

## 🎯 Objetivo
Criar um site temático para fãs de Pokémon, com páginas interligadas, mídias, curiosidades e um design responsivo.

## 📄 Páginas
- index.html: Página inicial
- curiosidades.html: Fatos interessantes
- jogos.html: Jogos clássicos
- pokemons.html: Lista de Pokémon famosos
- contato.html: Formulário de contato

## ⚙ Tecnologias
- HTML5  
- CSS3  
- JavaScript  

## 🚀 Deploy
O site está hospedado no GitHub Pages.
